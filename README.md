# FiscalFácil

Demo con datos ficticios. Abre https://sarrglx.github.io/fiscalfacil/ para probarla. Usuario: santiago.demo. Clave de práctica: demo1234.

Incluye guía, calendario, importación CSV/Excel/XML ficticio, revisión y asistente simulado. No realiza trámites ni comparte datos reales. Descarga FiscalFacil-proyecto.zip para editar el proyecto completo en VS Code. La página publicada usa los archivos JavaScript de esta carpeta; no requiere compilación.
